# PYTHO Labs

Web institucional inicial de **PYTHO Labs** para presentar el proyecto de investigación en fitoterapia y el token **PYTHO**.

## Ejecutar

Abre `index.html` en el navegador. Es un sitio estático; no necesita compilación.

## Publicar en GitHub

En Windows, instala [Git](https://git-scm.com/download/win) y [GitHub CLI](https://cli.github.com/). Descomprime esta carpeta y ejecuta desde PowerShell:

```powershell
cd C:\AI\pytho-labs
Set-ExecutionPolicy -Scope Process Bypass
.\PUBLICAR_GITHUB.ps1
```

El script intenta crear el repositorio público `pamunoz-des/pytho-labs` y subir la primera versión. Si el repositorio ya existe, se detiene sin sobrescribirlo.

## GitHub Pages

En GitHub entra a **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

La URL esperada *después* de habilitar Pages es `https://pamunoz-des.github.io/pytho-labs/`.

## Antes de utilizar el sitio comercialmente

- Adjuntar un whitepaper revisado.
- Validar las afirmaciones científicas y los supuestos financieros.
- Obtener revisión legal de los derechos económicos del token y cualquier oferta pública.
- Añadir contactos, privacidad y términos.

Este prototipo no vende tokens ni distribuye utilidades.
