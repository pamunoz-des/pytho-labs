Abre index.html en cualquier navegador. Incluye estilos y scripts integrados y recursos gráficos en assets/.
Para publicarlo en GitHub Pages, Cloudflare Pages o Netlify, sube el contenido de esta carpeta y usa index.html como inicio.

- Reemplazar el botón de whitepaper por el enlace a la versión aprobada.
- Revisión jurídica del token, derechos económicos y marketing de la emisión.
- Validar y documentar supuestos financieros y afirmaciones científicas.
- Agregar dominio propio, contacto, políticas de privacidad y términos.
- Reemplazar imágenes de referencia conceptual por recursos propios/licenciados.
